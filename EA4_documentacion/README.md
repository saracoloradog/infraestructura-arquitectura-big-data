# EA4. Arquitectura y modelo de datos

Esta evidencia consolida el proyecto desarrollado en EA1, EA2 y EA3. El informe presenta la arquitectura general, el flujo automatizado, el modelo físico de SQLite, las relaciones lógicas con los catálogos y la justificación de las herramientas utilizadas.

## Entregable

El PDF definitivo se encuentra en [`docs/arquitectura_modelo.pdf`](../docs/arquitectura_modelo.pdf).

Incluye:

- Arquitectura desde la API hasta el dataset enriquecido.
- Explicación de la simulación de servicios en la nube.
- Esquema de la tabla `products` y campos derivados.
- Relaciones entre productos y seis catálogos externos.
- Justificación de SQLite, Pandas, PySpark y GitHub Actions.
- Controles, trazabilidad, conclusiones y recomendaciones.
